# 着陆页生成（Landing Page）

营销/展示页面的生成流程。借鉴 deerflow frontend-design 与 ppt-generation 技能的三个关键设计：先研究后生成、风格字典前置、反 AI-slop 清单。

## 何时介入

生成 landing page、活动页、产品介绍页、个人主页等以「传达与转化」为目的的单页。

## 硬约束（生成前与用户确认）

一、入口文件必须是 index.html（标准托管即开即用）；默认单文件交付（CSS/JS 内联，图片用绝对 URL 或 data-URI），除非用户要求工程化项目。
二、移动端优先（375px 起）响应式：375/768/1200 三档断点必须过。
三、性能红线：无构建依赖（原生 HTML/CSS/JS 或用户指定栈）；首屏无阻塞资源；Lighthouse 四项 ≥90 为目标。
四、先研究后生成（pre-research gate）：任何「基于通用知识直接生成」都被禁止——先完成轻量研究（产品事实/受众/参照页），见下方流程。

## 流程：研究 → 风格字典 → 生成 → 自检

### 第 1 步 轻量研究（不跳过）

用 ask_user_question 收集：产品一句话与目标受众、核心转化动作（注册/购买/留资/下载）、必须有的事实（价格/数据/客户名）、参照风格。信息不足时用 web_search 补（竞品页/行业标准做法）。产出：5 条以内「必须传达的信息」清单。

### 第 2 步 风格字典（生成前落定，全程不变）

一、视觉方向：从明确方向中选一个并彻底执行（极简瑞士/暗色高级/渐变现代/杂志编辑/粗野主义/玻璃拟态/3D 等温/编辑排版——每次生成换方向，禁连续两单同款）。
二、落定 token：色板（hex 值，60-30-10 配比）/ 字体对（标题字体有性格，正文系统栈）/ 间距模数 / 圆角 / 阴影层级 / 动效清单（只用于反馈引导，150-300ms）。
三、意象与布局：hero 构图（大字/大图/分屏三选一）、区块顺序、每屏一个焦点。

### 第 3 步 生成

一、结构参考：hero（一句话价值＋CTA）→ 社会证明（数据/客户标）→ 特性（不等权重布局）→ 深入说明 → 常见问题 → 最终 CTA。可按研究结论裁剪。
二、反 AI-slop 清单（每条命中即改）：紫蓝渐变白底圆角卡组合/Inter-Roboto 万金油/三等宽特性卡/emoji 图标/无意义浮动动效/lorem 占位/渐变文字大阴影。与 ui-designer 技能清单一致，双处维护。
三、文案真实语境（从第 1 步事实清单来），无事实处留 TODO 标注而不是编造。
四、可访问性：语义标签/键盘可达/对比度 ≥4.5:1/图片 alt。

### 第 4 步 自检（交付前）

一、三档断点走查（描述每档布局）；二、反俗套清单逐条过；三、CTA 在首屏可见且唯一目标明确；四、打开文件无控制台错误；五、用 present 声明交付物。

## 交付

index.html（＋资源如用户要求分离）＋ 一段风格说明（方向/token/为什么适合该产品）。

## 业界基准（2026-11-01 联网核验）

一、转化背景权威数据（Baymard Institute，长期大样本研究）：购物车平均放弃率 70.22%——着陆页的第一使命是消解犹豫：社会证明、明确 CTA、风险逆转（退款/保障）置于首屏。
二、性能即转化：Core Web Vitals 官方阈值（LCP ≤ 2.5s / INP ≤ 200ms / CLS ≤ 0.1）是硬门禁；经典量化研究 Deloitte《Milliseconds Make Millions》（2020）：交互延迟每降 0.1s，零售转化约 +8%（引用时注明为 2020 年研究，条件适用性自行评估）。
三、移动优先不是选项：移动流量占主导的结论在 Google 多年研究中稳定成立——375px 断点即主战场。
